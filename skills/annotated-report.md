# 报告交付协议：md + 批注 HTML 双格式

## 为什么

用户的批注工作流（Hermes 批注插件）移植到 DSH 生态后，落地形态为**自包含单文件批注 HTML**：
不依赖任何服务（DSH web 不需要跑）、不依赖 Hermes，双击打开（file:// 即可）就能选中文字写批注、
高亮在 localStorage 持久化（同一浏览器下次打开还在）、支持批注列表/定位/删除/一键导出 md。

**凡是交付报告，就必须给用户双格式**：`.md`（源/可编辑）+ `.html`（批注版/阅读批注）。
这是默认行为，不是可选增强。

## 工具与位置

> 注：转换工具（md2annotate.py + engine.js + style.css）是**外部可选依赖**，不随 cleverer-dsh 分发。
> 获取方式：①从 `hermes-desktop-page-plugins` 生态的 dsh-annotate 目录复制；②或自行实现等价的 md→自包含批注 HTML 转换（协议见下）。

- 转换脚本：`<dsh-annotate>/md2annotate.py`（外部工具，按实际位置替换）
- 引擎/样式：同目录 `engine.js` + `style.css`（转换时自动内联，产物自包含）
- 产物约定：输出到 **md 同目录**、同名 `.html`（默认），或按用户要求指定路径

## 步骤（必须全部执行）

1. **写 md 报告**（正常 markdown）：
   - 第一个 `# ` 标题 = 文档标题（页面标题/批注存储 key 都取自它）
   - 层级清晰（`##`/`###` 会被生成目录锚点链接）
   - 表格/代码块/引用/列表全部支持，正常写
2. **转换**（用 pwsh 工具执行）：
   ```
   python "<dsh-annotate>/md2annotate.py" "<报告.md>" [<输出.html>]
   ```
   省略输出路径 = 与 md 同名 `.html`。中文路径/中文文件名无问题。
3. **验证**（交付前必做）：
   - 转换输出 `OK title=... blocks=... stream_chars=...` 无 ERROR/AssertionError
   - 输出文件存在且非空：`Test-Path` + 大小 > 10KB（长报告更大）
   - 有 `data-o` 块数、标题数打印即数据层通过
4. **交付说明中同时给出两个文件**，并注明：
   - `.md` 可编辑源
   - `.html` 双击打开即可批注（推荐浏览器 Edge/Chrome；批注存在浏览器本地，换浏览器/换机器不共享）
5. **DSH web 运行中时，额外给批注页链接**（两种入口都可用）：
   ```
   http://127.0.0.1:3080/annotate?file=<url编码的批注HTML绝对路径>
   ```
   链接由 `[uri]::EscapeDataString("<绝对路径>")` 编码后拼入；web 未运行时该链接打不开，此时用户用文件双击入口即可（交付说明里两个入口都写，注明 web 版需 DSH web 运行）。web 页面批注存 localStorage（按 docId 隔离），与文件版互不干扰。

## 验收清单（自检）

- [ ] 输出目录里有 `.md` 与 `.html` 两个文件（同名）
- [ ] HTML 打开后顶部工具栏显示：📄 Markdown 源 / 🔗 目录 / 📋 批注列表 / 📥 导出 / 🗑 清空
- [ ] 选中正文文字 → 弹气泡 → 写批注 → 保存 → 高亮出现
- [ ] 刷新页面 → 高亮恢复（localStorage 重放）
- [ ] 页面内"📄 Markdown 源"链接指向同目录 md 文件

## 陷阱

- **绝不手工编辑生成的 HTML**（data-o 是累计偏移，改一个字符后面全部错位）——要改内容就改 md 重新转换
- **md 里的裸 HTML**（如 `<div>` 包文本）不会被标注（引擎与转换器都跳过无块级祖先的文本），属正常；报告正文用标准 markdown 即可
- **不要用单反引号包整段命令**（pwsh 工具里反引号是转义符）；脚本路径用双引号包
- 批注存储 = localStorage（按 HTML 文件隔离）：隐私模式/换浏览器会丢批注，交付说明里提示用户
- 代码块内空白/换行会原样保留（偏移按 textContent 计算，一致）
- 同一 md 重复转换会覆盖旧 HTML（旧文件里的批注随 localStorage key 变化消失——key 取自页面标题，标题没变则批注仍可命中；但**覆盖前先确认用户没有在该 HTML 上留批注**）
